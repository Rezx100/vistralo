# Fictional sample content

These fixtures are original authored Vistralo demonstration content, available only in the explicit sample workspace. They contain no customer recordings, user project data or third-party website screenshots.

`sample-walkthrough.mp4` is a silent 12-second, 1280 × 720, 24 fps demonstration showing three fictional storefront interface states. It is an authored video fixture, not evidence of a screen recording, a live website analysis or a provider job. The production detail viewer identifies it as a 12-second sample; fictional card durations exercise the duration layout separately.

`walkthrough-poster.webp` and the responsive 480, 820 and 1240 pixel AVIF/WebP posters are decoded from its stable frame at 1 second, within the first 20% of the video. Each rendition uses a single Lanczos resize and never upscales. WebP uses quality 82; AVIF uses libaom CRF 32 because FFmpeg's encoder has no direct quality-60 setting. The retained source is the demo video.

`sample-brief.md` is a complete readable five-section visual brief with 14 interaction references. The app renders its own document thumbnail from the same brief content model.

# Archivo

Self-hosted Archivo variable upright Latin subset, weight axis 100–900 and width axis 62–125%. It sets titles (wide) and the print along a frame's edge (condensed); see `DESIGN.md`.

- Original project: https://github.com/Omnibus-Type/Archivo
- Distributed source: `@fontsource-variable/archivo` 5.3.0, `files/archivo-latin-wdth-normal.woff2`
- License: SIL Open Font License 1.1, included verbatim in `OFL-Archivo.txt`.
